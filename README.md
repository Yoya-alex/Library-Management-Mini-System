# Library Management Mini System

This project is a **Software Configuration Management (SCM) mini project** developed by a group of six Software Engineering students. It is designed to demonstrate SCM concepts applied in a practical software development scenario.

---

## Project Description

The **Library Management Mini System** is a lightweight web-based application that simulates basic library management tasks. It allows a librarian to:

- Log in securely.
- Access a user-friendly dashboard with system statistics.
- Manage the library's book records stored in a JSON file, including viewing, adding, updating, and deleting books.

This project focuses on **practical implementation of SCM principles**, while providing a functional interface for managing library resources in a small-scale environment.

---

## Features

- **User Authentication**: Only authorized librarians can access the system.
- **Book Management**: Add, update, delete, and view books.
- **Data Storage**: All book data is stored in a structured JSON format.
- **Dashboard**: Provides a snapshot of library resources.
- **SCM Integration**: Demonstrates configuration management processes such as versioning, change tracking, and baselines.

---

## Technologies Used

- **HTML** – For building the web interface.
- **JavaScript** – For dynamic interaction and logic handling.
- **JSON** – For lightweight data storage and management.
- **Git & GitHub** – For version control, collaboration, and SCM practices.

---

## Project Focus

This project emphasizes **Software Configuration Management** concepts, including:

- **Configuration Item Identification** – Identifying key artifacts such as source code, documentation, and test cases.
- **Version Control** – Using Git to track changes and maintain history.
- **Change Control** – Managing modifications through commit messages, pull requests, and approvals.
- **Baselines & Releases** – Establishing stable versions of the system.
- **Configuration Audits** – Reviewing and verifying system changes and documentation for completeness and correctness.
